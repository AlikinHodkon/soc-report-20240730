# Отчёт о расследовании сетевого инцидента

## 1. Краткий обзор (Executive Summary)

30 июля 2024 года в локальной сети организации `wiresharkworkshop.online` зафиксирована подозрительная активность на рабочей станции `DESKTOP-SKBR25F` с IP-адресом `172.16.1.66`.

В ходе анализа сетевого трафика обнаружено взаимодействие заражённой станции с командным сервером (C2), связанным с вредоносным программным обеспечением **STRRAT версии 1.6**. Соединение осуществлялось с внешним IP-адресом `141.98.10.79` через TCP-порт `12132`.

В период с 05:40:07 до 05:48:34 (UTC+3) рабочая станция отправила на C2-сервер 102 сообщения типа `ping`, содержащих сведения о системе и текущем пользовательском окружении. В частности, передавались имя компьютера, имя пользователя, версия операционной системы, сведения об антивирусной защите и информация об активном окне.

Также в сетевом трафике обнаружены обращения к контроллеру домена `172.16.1.4`, связанные с протоколами DCE/RPC и SMB. По результатам исходного разбора Wireshark, часть обращений была связана с получением сведений об учётных записях и группах Active Directory. Эти данные могут свидетельствовать о разведке внутри доменной сети.

В ходе анализа не обнаружено входящих команд от C2-сервера в исследуемом сетевом потоке. Также не получено достаточных доказательств выполнения команд оператора, кражи конкретных файлов, применения DCSync или шифрования данных.

Первоначальный вектор проникновения установить не удалось: захват трафика начинается уже после начала подозрительной активности.

Временной интервал исследуемого захвата: **30.07.2024, 05:38:48–05:48:34 (UTC+3)**.

| `185.199.110.133` | TCP/443 | HTTPS-трафик, связанный с GitHub |

Взаимодействие с ним подтверждается следующими пакетами:

### 3.3. Индикаторы вредоносного ПО

В сетевом взаимодействии с C2-сервером обнаружены признаки использования **STRRAT версии 1.6**.

В частности, в сообщениях присутствует идентификатор вредоносного ПО `STRRAT`, а также идентификатор заражённого клиента:

`1BE8292C`

Пример сообщения, отправленного заражённой рабочей станцией:

`ping|STRRAT|1BE8292C|DESKTOP-SKBR25F|ccollier|Microsoft Windows 11 Pro|64-bit|Windows Defender||1.6|US:United States|Not Installed|1 Sec`

Сообщение содержит:
- название вредоносного ПО и его версию;
- идентификатор клиента;
- имя компьютера;
- имя пользователя;
- сведения об операционной системе;
- информацию об антивирусной защите;
- дополнительные параметры состояния заражённой системы.

### 3.5. Активность внутри доменной сети

В трафике обнаружены обращения от рабочей станции `172.16.1.66` к контроллеру домена `172.16.1.4`.

Зафиксированы соединения с использованием DCE/RPC и SMB, в том числе обращения к RPC-службам контроллера домена.

Согласно исходному разбору Wireshark, в одном из SMB2 IOCTL-запросов (пакет № 1065) присутствовали вызовы SAMR, связанные с поиском учётных записей и получением сведений о группах пользователей.

Также обнаружены обращения к службе DRSUAPI на контроллере домена. Однако в исходном разборе не обнаружено операции `DRSGetNCChanges`, поэтому имеющихся данных недостаточно, чтобы утверждать, что была выполнена атака DCSync.

Таким образом, сетевой трафик указывает на взаимодействие с инфраструктурой Active Directory и возможную разведку доменной среды, но сам по себе не доказывает успешное получение секретных данных домена.

### 3.6. Файловые индикаторы и SHA256

В рамках анализа предоставленного сетевого дампа не удалось извлечь исполняемые файлы, для которых можно было бы вычислить SHA256-хеши.

Поэтому файловые хеши в отчёте не приводятся.

### 3.7. Ограничения исследования

Исследование проводилось на основании предоставленного файла сетевого захвата `network.pcap`.

В связи с этим:
- первоначальный вектор проникновения установить не удалось;
- содержимое HTTPS-соединений не анализировалось, поскольку трафик был зашифрован;
- наличие сетевого взаимодействия с внешними ресурсами не позволяет однозначно установить, какие именно файлы передавались;
- входящие команды от C2-сервера в исследуемом потоке не обнаружены;
- доказательства кражи конкретных файлов, выполнения команд оператора или шифрования данных отсутствуют.

Выводы отчёта ограничены информацией, доступной в исследуемом сетевом дампе.
